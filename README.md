# 1688 聊天记录批量导出

这是一个 Chrome 扩展原型，用于在已登录的 1688 工作台中读取并导出聊天记录。本目录基于 2026 年 7 月创建、后续归档的 `1.1.3` 版本整理。它与另一个名为 LAI 助手的后续分支并非同一份源码。

## 当前状态

本项目是历史原型。已检查 JavaScript 语法和 manifest 引用的文件是否存在；尚未在当前 1688 页面上验证登录、抓取、导出完整性或定时任务。1688 页面调整后可能无法正常工作，使用前请用无敏感信息的测试数据核对结果。

## 安装

1. 使用 Chrome 打开 `chrome://extensions/`。
2. 打开“开发者模式”，选择“加载已解压的扩展程序”。
3. 选择本目录，然后登录 1688 工作台并打开聊天记录页面。

## 数据与权限

扩展需要访问 1688 工作台页面，并使用下载、存储、定时任务、通知和标签页等浏览器权限。导出的聊天记录可能包含客户个人信息，请妥善保管导出文件；不要将真实聊天记录或账号信息提交到 GitHub。扩展设置和定时任务状态使用浏览器本地存储。此原型尚未经过完整的安全和隐私审计。

## 项目来源

该版本对应 2026-07-30 的“做一个1688平台插件，可以批量下载客户的聊天记录”项目。仓库整理时不包含用户聊天记录、真实客户数据或账号配置。项目尚未指定开源许可证，使用和再分发权限以权利人实际授权为准。
